# VinhWorks Auth UI

Giao diện xác thực (Login / Register) được xây dựng với **Next.js 14 App Router**, **Framer Motion**, và **Tailwind CSS**. Thiết kế split-screen: LEFT — visual showcase 3D tilt, RIGHT — form đăng nhập/đăng ký.

---

## Tech Stack

| Package           | Version | Mục đích                            |
| ----------------- | ------- | ----------------------------------- |
| `next`            | 14+     | App Router, Image, Link             |
| `framer-motion`   | 11+     | Animation, 3D tilt, AnimatePresence |
| `tailwindcss`     | 3+      | Utility-first styling               |
| `lucide-react`    | latest  | Icon set                            |
| `react-hot-toast` | latest  | Toast notifications                 |
